# 随身护照

基于 FoloToy AI Passport 官方 BSP 的独立应用。分支：
`feature/athena-hermes-muse-companion`。上游基线提交：
`a06235e4c94361e3f8a2d498930254101718acae`。

视觉参考为[口袋百宝箱，玩法 438](https://ai-passport.folotoy.cn/plays/438/)：
单色头像首页、头像旁的 PSI 与天气、个人名片、独立应用目录。本实现重新编写了
LVGL 页面和导航，不使用基线硬件测试菜单，也不包含参考应用未公开的整机固件。

## 功能与操作

| 页面 | 操作和行为 |
| --- | --- |
| 首页 | NEA 24 小时 PSI 替代时钟。上：名片；下：巴士到站；确定：应用目录；长按下：手机设置热点 |
| 应用目录 | 上下选择；确定进入；长按确定回首页 |
| 个人名片 | 显示保存的头像、名字、签名和联系方式；确定键循环切换名片 / 二维码 / NFC 碰一碰提示 |
| Athena | 通过电脑桥接读取 4177 额度；上下切换账号；确定刷新 |
| Hermes | 手机设置页输入文字；设备上下翻页阅读；长按下键录音，松开后通过已配置电脑桥接发送 |
| Muse | 官方 Muse AI / Muse Passport 集成进行中，尚未提供可用的蓝牙聊天 |
| 电台 | 上下换台；确定播放/暂停；长按上下调音量并即时显示百分比；长按确定停止并退出 |
| 天气 | 新加坡/马来西亚城市天气；确定刷新 |
| 手机设置 | 显示 IP 和每次启动随机生成的设置码；上下选择已有 Wi-Fi 预设，确定保存并连接；长按下配置 Wi-Fi，长按上切换语言 |

应用内长按确定返回目录。音频工作任务独占采样格式、音量和 PCM 播放。
按键回调只入队，网络与音频由工作任务处理，LVGL 任务外的界面操作均加锁。

## 更换头像

1. 进入手机设置。首次没有 Wi-Fi 配置时自动开启 WPA2 热点；否则在首页或设置页
   长按下键开启热点。
2. 手机连接屏幕显示的热点，输入屏幕上的密码，打开显示的 HTTP 地址，再输入
   六位设置码。
3. 选择照片，调整缩放、水平和垂直位置，保存新头像。浏览器把裁剪结果转成
   80 x 112 RGB565；照片不会上传云端。
4. 名字、签名、联系方式、城市、主题和桥接配置分别保存。密码或令牌留空表示保留
   原值。Wi-Fi 修改后重启生效，头像和个人资料立即更新。

设置热点没有互联网；手机提示时保持连接。使用 2.4 GHz Wi-Fi。
设置页和桥接的 HTTP 只用于可信局域网，不应暴露到公网。设置 API 不返回已保存的
密码和令牌，每次启动的设置码不同。

## NFC 碰一碰打开主页

Passport 内置被动式 NTAG213 NFC 标签，没有与 ESP32-C3 相连：固件无法写入或
更改它，也无法感知被碰触，且没有对应的 BSP API。个人名片的第三个视图
（按两次确定键）只是向拿着手机的人说明如何碰一碰。

使用前先用手机写入标签一次：

1. 在手机设置页保存个人链接（与二维码视图相同的**名片二维码链接**；
   LinkedIn 链接可以轻松放进标签约 144 字节的可用空间）。
2. 在 NFC Tools 等 NFC 写入应用中选择**写入 → 添加记录 → URL/URI**，
   填入同一链接，选择**写入**，把手机贴近 Passport 背面的 NFC 标记处。
3. 尽量用另一部手机测试：把手机贴近背面，点开弹出的横幅或通知打开链接。
   较新的 iPhone 和大多数 Android 手机在亮屏时都能在后台读取 NDEF URL
   标签；对方手机不需要装应用，Passport 关机也能读取。

标签里只能存一个固定链接。要更改时重新写入标签，或者把标签指向你自己的
链接页，之后只改目标地址即可。写完后可在写入应用里给标签设密码或锁定，
避免在聚会上被别人覆写。

## 息屏与省电

在所有页面，10 秒没有按键操作后显示屏进入息屏：背光关闭，页面数据抓取
暂停，直到下一次按键。唤醒的这一次按键只负责点亮屏幕，不会同时触发
导航、开关电台或开始录音；唤醒后当前页会刷新：巴士到站数据在唤醒时抓取
（若 60 秒缓存仍新鲜则直接使用缓存），天气与列车定时器也不会在黑屏期间
触发，而是到期后在唤醒时立即补上。

息屏期间特意保持 Wi-Fi 连接并启用调制解调器省电模式。断开连接会在每次
唤醒时付出完整的重新连接、重新关联和 TLS 会话成本，以这个超时时长计算
反而更耗电；省电来自停止抓取。电台播放、语音交互和打开着的手机设置页
视为正在使用，会保持屏幕常亮。

## 电脑桥接与助手范围

见[电脑端说明](../../companion/README.zh_CN.md)。桥接读取 Athena、获取 Open-Meteo
天气、通过 ffmpeg 解码十个预置电台，并转发助手请求。开发电脑上的 Hermes 为
`http://127.0.0.1:8642/v1`，
桥接局域网地址为 `http://<computer-LAN-IP>:4188`。这些是运行时配置，不是固件中的
固定地址或内置密钥。

Muse 指官方 Muse AI 账号与 [Muse Passport 手机伴侣](https://github.com/FalkoWing/muse-passport)，本应用沿用原版伴侣协议，用户已确认配对后的语音回复有声。
Hermes 支持手机文字输入，以及通过已配置电脑语音桥接进行长按下键录音、松开发送。
手机浏览器转发已实现 Hermes 麦克风上传、取消和回复音频。用户已确认家庭 Wi-Fi 及 Android 热点/Tailscale 手机转发的 Hermes 语音正常。
本构建不包含直播电视、小智云语音、游戏、PM2.5 或 GPS。
[TV 项目](https://github.com/zpdeng1020-coder/ai-passport-tv)是参考项目，并非已集成电视功能。

烧录前必须针对具体产物取得明确确认。

## NEA 烟霾指标

首页以最新发布的 **24 小时 PSI**、NEA 等级、报告区域及新加坡时间的读数时间替代
时钟。它不是瞬时颗粒物测量值。两套主题中，数值超过 100 使用醒目的警示色。
没有位置、请求失败和数据过期都有明确状态，不会虚构低值或良好状态。

在手机设置选择中区/北区/南区/东区/西区，或使用坐标模式。坐标模式匹配离保存位置
最近的 NEA 官方报告区域标注中心，不是按官方区域边界多边形判定。设备没有 GPS，
也不连续追踪位置。保守的新加坡范围矩形排除较远坐标；所选天气城市也必须是新加坡。
其他城市显示 NEA 仅覆盖新加坡。

手机定位按钮要求 HTTPS 或 localhost。普通设备 HTTP 页面无法取得浏览器定位，
此时手选区域或填写坐标，页面会解释限制。坐标仅保存在设备并发送到本地桥接，
NEA 请求获取全部区域数据，不包含个人坐标。烟霾配置使用独立 NVS 键，保留现有
资料/配置 blob 格式。

桥接缓存有效 NEA 数据五分钟，上游失败时保留有效缓存，并将刷新失败或读数超过
两小时的数据标为过期。设备展示来源读数时间，不把请求时间当成读数时间。
未配置位置的设备会提示选择区域，不默认假设用户位于中区。

来源：[NEA PSI API](https://api-open.data.gov.sg/v2/real-time/api/psi)、
[NEA PSI 定义](https://www.nea.gov.sg/our-services/pollution-control/air-pollution/faqs)。
执行 `python3 tests/test_passport_haze.py` 检查等级边界、区域、位置、缓存、异常数据
与过期状态。软件预览使用示例数据；真实位置切换、设置保留及屏幕输出仍需设备验收。

## 巴士到站：LTA DataMall

巴士到站直接使用官方 **LTA DataMall v3 Bus Arrival API**。
设备通过自身网络联网，此功能不需要电脑桥接；不会回退调用 Bus Aunty 托管 API。

1. 申请自己的 [DataMall Account Key](https://datamall.lta.gov.sg/content/datamall/en/request-for-api.html)。
2. 打开 Passport 手机设置网页，输入当前六位设备设置码，等待读取已保存资料。
3. 在 **LTA API 密钥**填写密钥，点击**保存设置**。以后编辑时留空会保留已有密钥，
   已保存密钥不会回传给浏览器。
4. 在首页按**下键**进入巴士到站，再按**确定**刷新。提示缺少密钥时请完成第 3 步；
   密钥被拒绝表示 LTA 未批准该次请求。此密钥与电脑桥接访问令牌不同。

默认收藏 **Eunos Int（82009）**。手机页面最多保存十个收藏站点，
每行填写 `站点代码 | 名称`，保留前导零。每页四行，显示服务号和最多三班到站分钟数。
**Arr** 表示即将到站，**60+** 表示超过一小时，**--** 表示不可用。
目的地显示为 **To stop 54009** 等站点代码；此构建没有从 LTA 独立的 Bus Stops
数据集读取目的地名称。不同目的地和访问次数保持独立，不会合并。

上下键翻页和切换收藏站，确定刷新，长按确定返回菜单。
请求缓存六十秒，失败后按 120/240/300 秒退避。界面更新时间表示本次成功**获取时间**，
不是 LTA 来源时间。刷新失败或数据超过三分钟会标记过期，并隐藏倒计时。

可选的电脑桥接巴士路由需要在桥接进程的私人环境中设置 **`LTA_ACCOUNT_KEY`**，
再重启桥接。这与保存在 Passport 上的密钥相互独立。
不要把真实密钥写入受 Git 跟踪的文件、命令行参数、固件默认值或截图。
`GET /v1/bus?stop=82009&page=0` 仍需正常的桥接 Bearer 鉴权。
桥接端缺少密钥时返回 `lta_key_required`，不会改用其他运营方服务。

数据来源：**新加坡陆路交通管理局（LTA）**，通过
[LTA DataMall](https://datamall.lta.gov.sg/) 获取，遵循
[Singapore Open Data Licence](https://data.gov.sg/open-data-licence) 与
[LTA API 条款](https://datamall.lta.gov.sg/content/datamall/en/api-terms-of-service.html)。
[API 文档](https://datamall.lta.gov.sg/content/dam/datamall/datasets/LTA_DataMall_API_User_Guide.pdf)。
本项目独立开发，不代表 LTA 背书；到站预测可能变化。
此前参考的 [Bus Aunty Mini](https://github.com/awesomelionel/bus-aunty-mini)
及其 MIT 版权声明继续保留。

## Android 热点与户外使用

巴士到站、NEA PSI 与 Open-Meteo 天气现在由设备通过手机的 2.4 GHz 热点直接
使用 HTTPS 获取。NTP 同步时间后才能验证 TLS 证书，首次连接可能需要等待。
天气缓存十分钟，PSI 五分钟，巴士一分钟；刷新失败会标记过期。
PSI 位置为已保存区域或坐标，并非持续定位；移动后请更新。马来西亚不在 NEA PSI 覆盖范围。

Android 的 Tailscale 不会自动把热点客户端流量送入 VPN。使用 Hermes 时，
**在手机上**打开设备设置页，勾选“通过手机 Tailscale 转发”，输入电脑的
Tailscale 桥接地址与访问令牌，再发送消息。保持页面开启直到回复同步到设备。
令牌须在本次页面会话重新输入，已保存秘密不会回显。手机浏览器须使用 Tailscale VPN。
浏览器的本地网络或 CORS 限制可能阻止转发，真实 Android 验收尚未完成。
失败会在手机与设备显示错误。

桥接服务需监听 Tailscale 地址并启用 `--phone-relay`，参见 companion 说明。
服务仍仅在局域网及 tailnet 内可用，家中电脑需保持开机。输入地址和令牌后，
点击**连接手机转发**可转发 AI 用量及广播。保持页面在前台、手机保持唤醒；
用量每 30 秒更新，设备按键控制选台、播放和音量。PCM 使用最大 1,024 字节的
有界数据包，并处理队列反压及播放代次。八秒未收到心跳时停止设备播放。
**停止转发**恢复直连模式。Muse 仍使用独立的官方蓝牙集成，不是 HTTP 本地模型助手。

应用目录支持循环选择：第一项按上键跳到第八项，第八项按下键返回第一项。

## 私人 Wi-Fi 配置与备份

可在被 Git 忽略的 `.local/passport-defaults.json` 保存 home、outside 两个 WPA2
网络，生成器仅把本地配置写入构建目录的私有头文件。普通干净克隆不含任何凭据。
不要提交配置、生成头文件、包含密码的固件或 ELF。设备可保存后续手动修改；
每次本地配置内容变化时，固件只应用一次新的默认网络，保留名片、照片与其他设置。

同一私人 JSON 可包含 `bridge_url` 与 `bridge_token`，仅用于补齐设备中缺失的桥接设置。
只有已保存地址与私人配置地址相同时才补齐令牌，已有非空设置保持不变。
可选 `bridge_lan_url` 在 Home 网络下选择电脑局域网地址，但仅在保存地址仍匹配
`bridge_url` 时生效；手动保存的其他地址优先，原 Tailscale 地址仍供手机页面使用。
修改这些字段不会重新应用默认 Wi-Fi。认证设置完成后，设备仍需能通过网络连接电脑。

本地 USB 验收可设置 `usb_test_control: true`，启用严格匹配的 USB 控制台命令：
`@passport status`、`@passport up/down/ok`、`@passport hold-up/hold-down/hold-ok`。
按键命令使用与实体按键相同的输入队列。状态仅报告计数、连接状态和堆内存，
不输出凭据、个人资料或助手回复。输入有长度限制且不阻塞，普通干净构建默认关闭。

私人 USB 诊断另支持 `@passport wifi-awake`（b/g/n、关闭调制解调器休眠）、
`@passport wifi-legacy`（仅 b/g、关闭休眠）、`@passport wifi-normal`（恢复 b/g/n 和休眠）。
`@passport wifi-baseline` 可测试连接期间启用调制解调器休眠。临时模式不改变
已保存凭据，重启后恢复，也不会自动降低协议。`@passport setup` 为本地 USB 网页/API
测试输出当前设备 IP 和设置码；该输出属于秘密，不可加入 Git。
TLS 保留 16KB 入站记录支持和完整 CA 验证，使用动态缓冲及 1KB 出站记录，
为证书验证留出更多 SRAM。

在设备“设置”页，上下键选择“在家 Home”或“手机热点”，短按确定保存并连接，
无需重启。Wi-Fi 与语言命令使用独立优先队列，后台轮询不会静默丢弃这些命令。
私人兼容性试验以外保留正常的调制解调器节电设置。
长按下键仍可开启手机设置热点，长按确定返回应用。
手机设置页也有网络选择，保存成功状态现在同时显示在“保存设置”按钮下方。
手机保存网络后仍需重启设备应用；密码不会回显。

用户要求的私人备份放在 `.local/backups/`，包括原始 profile 分区、解码配置及设备
80 x 112 头像导出。备份含密码和令牌，只存本机，不能上传 GitHub。设备头像不是
手机原图；仅保存在 RAM 的助手回复不在备份中。恢复前须匹配分区布局，不能
把 profile 数据当成完整固件从 0x0 刷写。


## 二维码、语言与连接诊断更新

名片页短按确定切换资料与二维码。手机设置的二维码链接支持 HTTPS、HTTP 和微信链接；
用户自己的默认链接仅保存在忽略的私人构建配置中。语言切换为设置页长按上键，
或在手机页面选择中文/英文后保存。两个新设置使用独立 NVS 键，不改变已有资料结构。

输入手机设置码后，页面先通过鉴权的 `/time` 接口同步手机时间，再读取资料。
设备同时尝试三个 NTP 服务，证书验证保持启用。巴士和天气会显示更具体的失败类别。
Wi-Fi 在三次断开或连接期限到达后停止重试；错误原因以数字保留，按确定可重试。

AI 用量替代 Athena 的页面名称。桥接保留 `/v1/athena` 兼容接口，新增 `/v1/usage`，

### 修正预设密码、设置页排版与请求内存

手机选择 Home/Phone Hotspot 后仍可填写新密码，留空保留该预设原密码。
每个预设的密码覆盖值使用独立私人 NVS 键保存，重启和设备切换网络时继续使用；
不会回显密码，也不改变 Git 中的私人构建输入。
热点名称、最长密码和设置码限制在独立区域，地址使用较小的拉丁字体。
语言切换显式重绘不透明背景。公开数据仅在 Wi-Fi 已取得地址时发起请求；
响应缓冲由 1 KB 按需增长，仍保留原响应大小上限与 HTTPS 验证。

私人构建配置可包含 `psi_region`（`central`、`north`、`south`、`east` 或 `west`）。首次配置时仅补充尚未选择的区域并保存到 NVS，不覆盖已有选择。保存的初始化标记可避免用户清空区域后再次自动填入。公开构建保留未选区域状态。

电台工作任务在停止播放时完整释放 BSP 的 codec、I2S、DMA 资源及转发 PCM 队列，下次播放时重新初始化。队列创建、非阻塞读写和删除共用应用互斥锁，避免 HTTP 处理器向已删除队列写入，使退出电台后的 HTTPS 公共数据请求能够使用回收的内存。共享 I2C 总线保持可用，供显示与电量计继续使用。


## 列车警报

菜单 **02 列车警报** 复用巴士到站已保存的 DataMall AccountKey，设置为第 09 项。
九项菜单会滚动显示选中项，并支持首尾循环。首页下键仍然打开巴士到站。
有列车警报时，占用原有 NEA 元数据栏显示一行摘要，不遮挡头像、PSI 或天气，
不会发出提示音或振动。

首页和列车警报页自动请求两个 GTFS 数据集，间隔至少两分钟。
进入列车警报时获取详情快照，按确定可请求刷新。需要 Wi-Fi 和已同步时间。
网络工作任务串行处理 HTTPS 与天气请求，录音期间暂停新工作；
其他前台功能不轮询列车数据。离开列车警报页后释放详情内存，首页仅保留摘要、数量和状态。

服务警报按 communication_period 或旧版 active_period 判断当前是否生效，
区间为前闭后开，已过期或仅未来生效的消息不触发当前通知。
详情保留来源提供的各语言标题/说明、网址、受影响编号、时间区间、原因与影响代码及常见名称，
以及中断行程/站点预测、延误和取消信息。线路和站点编号按原值显示，不臆造站名或事故描述。
对于不定时更新的数据，旧的文件时间戳可能正常；获取失败才标记缓存，而不单凭时间戳判断。

为适配 ESP32-C3 内存，单个 protobuf 下载上限为 64 KiB，合并详情文本上限为 32 KiB。
超限、格式错误、差量数据或请求失败会显示错误/不完整状态，不能静默截断详情或宣称服务正常。
只有两个数据集都成功返回空快照，才显示当前未报告警报。
部分结果仍可阅读，但标注不完整/缓存；获取失败保留已有警报。
首页仅显示一行截短摘要，进入应用后按实际字体分页阅读原文。

AccountKey 仅用于固定的 DataMall HTTPS 元数据接口。
签名下载使用新的连接，不附带密钥或桥接令牌，也不自动跟随重定向。
下载网址仅允许文档规定的 LTA S3 域名和列车数据路径；签名链接和密钥不记录到日志或 Git。
