Set up your Passport

Start a route, add a book, or connect your music. Use this same page on Android or iPhone.

Turn-by-turn navigation

  1. On Android, enable Bluetooth. In Settings → Apps → Komoot → Permissions, allow Location and Nearby devices when requested. Menu names vary by phone.
  2. In Komoot, enable Bluetooth Connect if available, then start a route. Keep Komoot open for the first connection.
  3. On Passport, open Navigation and press OK. Wait for a street name and distance.

No computer or access token is needed for navigation. Komoot connects directly to Passport; this webpage does not pair Bluetooth devices.

Directions are not appearing?

Keep the phone nearby and check that the route is running. Stop and restart the connection with OK. Current phone compatibility still needs testing; the reference implementation was tested on iOS only. If your Komoot app has no Bluetooth Connect option, this connection may not be supported.

First-time Spotify setup

Spotify Premium and a configured developer app are required. Set SPOTIFY_CLIENT_ID on the companion. With the default callback, sign in once using a browser on the companion computer. Phone sign-in needs a registered HTTPS callback that reaches the companion; changing the callback to a plain HTTP LAN address will not work.
